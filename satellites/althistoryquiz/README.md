# Alt History Quiz — What If?

A fun, shareable alternate history personality quiz built with Next.js. Answer 12 randomly selected "what if" questions and discover your history-maker personality type.

## Personality Types

- **Timeline Divergent** — You see infinite possibilities in every moment
- **History Preserver** — You believe the past unfolded as it should
- **Chaos Agent** — You thrive on disruption and dramatic change
- **Future Architect** — You look at the past to engineer a better future

## Setup

1. Install dependencies:

```bash
npm install
```

2. Copy the environment file and fill in your keys:

```bash
cp .env.example .env.local
```

3. Run the development server:

```bash
npm run dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Build

```bash
npm run build
```

## Deploy

This project is configured for Vercel deployment. Push to your repository and connect it to Vercel, or run:

```bash
npx vercel
```

## Stack

- **Next.js 14** (App Router)
- **React 18**
- **TypeScript**
